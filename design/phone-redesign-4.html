安卓版四个方向，各自独立

现有手机端推倒重来。桌面端的全部能力原样保留——参考槽（参考图 / 姿势 / 服装 / 人脸）、画幅比例、描述、生成、历史、模板库——变的只是组织方式。下面四个方向是四套互不相干的交互范式和视觉性格，各自完整，选一个（或指定混搭）再展开成全套流程稿。

方案 A

快门台

隐喻：相机取景器。生成一张照片 ≈ 按一次快门。

画布就是取景框，占屏近半、永远在视线上方；四个参考槽收成一排圆扣；所有操作在拇指能到的下半屏完成。生成不是「点按钮提交表单」，而是「按下快门」——按住蓄力、松手出片，配合一次闪光过渡。

  • ①快门即生成：轻点生成一张，长按住不松手连拍多方案，松手停。
  • ②点任一槽位从底部弹出选源面板：相册选图 / 模板库导入 / 清空。
  • ③取景框上左右滑 = 翻这张的历史底片，右下角书签随手存模板。
  • ④左下角画幅角标一点即切换 1:1 / 3:4 / 4:3 / 9:16 / 16:9。
亮点
意图最直白：一眼看懂「摆好参考 → 按快门」。单手全程可达，仪式感强。
代价
相机隐喻会弱化「姿势 / 服装」这类非拍照直觉的槽位语义；四个槽位同排，第一次用时未必明白可叠加。
适合
核心诉求就是「快速出片」的轻用户；拍照 app 重度用户零学习。

方案 B

出图对话

隐喻：聊天。每次生成 = 发一条消息，成片 = 收到的回复。

不需要「页面」概念：附件（参考槽）+ 一句话 = 发送 = 生成。结果永远和当时的输入成对出现，往上滑就是完整历史，不用单独的历史入口。改需求就是再发一条：「换 9:16 再来一张」。

  • ①参考槽作为附件芯片随消息发送，发送键即生成键。
  • ②成片下的操作条：存相册 / 存模板 / 原条件再来一张。
  • ③会话永不清空，上滑即历史；顶部长按任意成片可跳到当时的参数。
  • ④[+] 面板收纳：四个参考槽、模板库、画幅快选。
亮点
零学习成本，结果与条件天然成对存档；「改一句话重出」的迭代路径最顺。
代价
画幅、多槽对比这类精确控制在聊天隐喻里只能收进面板；竖屏宽度的成片偏小，细看要再点开。
适合
把 AI 出图当「提需求」而不是「做操作」的大多数人。

方案 C

手势工作台

隐喻：口袋里的修图台。画布全屏，工具围着拇指长。

没有 Tab、没有表单：画布铺满全屏，四角是参考槽的落位格；参考像图层卡一样从左下角拖到角上占槽。工具收在右下角一段拇指弧上，生成是长按蓄力的环。给愿意学一套手势、天天出片的人。

  • ①参考卡拖到画布角 = 占槽；拖走 = 移除。四角即四个槽位。
  • ②长按画布唤出历史叠层，上下滑翻旧片，松手回落所选。
  • ③右下拇指弧放高频工具：画幅 / 描述 / 模板 / 历史，生成环长按蓄力出片。
  • ④双指捏合缩放看细节，单指拖移画布。
亮点
信息密度和操作效率最高，空间记忆强（东西永远在同个位置）；缩放细看成片最方便。
代价
学习成本四案中最高，手势没有可见入口，必须配引导层；左手单手基本不可用。
适合
高频重度创作者——桌面端那批用户的移动延伸。

方案 D

分步出片

隐喻：订机票式的引导流程。一屏只做一个决定。

四个步骤铺开：选模型 → 摆参考 → 写描述 → 出片。每一步只有一件事和一颗大按钮，参考槽一次只看一个、占满整屏宽——图大、字大、不迷路。左右滑在步骤间往返，参数全程保留。

  • ①顶部四格步骤轨：做过打勾、当前高亮，点任意格直接跳回改。
  • ②摆参考步：分段切换四个槽，每个槽一张大图 + 从模板库选 / 相册选 / 拍一张。
  • ③描述步给三句风格快捷句，点了即填，也可留空直接下一步。
  • ④出片步是全屏仪式：进度环 → 成片满屏 → 存相册 / 存模板 / 调整重出。
亮点
不可能迷路，参考图看得最清楚；给第一次接触的人和朋友装机最稳。
代价
熟练之后每张图都要走四步，效率低；步骤间的往返滑动比单屏切换多。
适合
新用户和低频用户；也可作为其他方案的「首次引导模式」。

看完之后

选定一个方向（或指定混搭，比如 B 的对话流 + C 的拖拽占槽），我把那个方向展开成完整流程稿：首次启动与引导、空态、生成中与失败重试、历史、模板库、接入自定义中转站的设置页，逐屏过完再进实现。

四稿彼此独立，没有共享的中间方案；每一稿的取舍都写在各自的「代价」里。
